## 查询页面

用 Vue 3 和 Vite 查询上面的单价，数据来自根目录的 `prices.json`。

```bash
npm install
npm run dev
```

浏览器打开终端里给出的本地地址。名称搜索会把前缀匹配排在包含匹配前面，分类下拉按数据里的分类筛选。
